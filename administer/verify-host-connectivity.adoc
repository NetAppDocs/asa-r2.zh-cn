= 验证ASA R2存储系统上的主机连接
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果主机数据操作出现问题、您可以使用ONTAP系统管理器验证从主机到ASA R2存储系统的连接是否处于活动状态。

.步骤
. 在System Manager中，选择*Host*。
+
System Manager 在主机组名称旁边显示主机连接状态：

+
** *正常*：表示所有启动器都连接到两个节点。
** *Partially Connected*：表示某些启动器未连接到两个节点。
** *未连接*：表示未连接任何启动程序。




.下一步是什么？
在您的主机上进行更新以解决连接问题。ONTAP 将每 15 分钟重新检查一次连接状态。
