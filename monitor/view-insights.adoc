= 使用 ASA r2 system Insights 优化集群安全性和性能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
查看ONTAP系统管理器中的_洞察力_、确定可在ASA R2系统上实施的最佳实践和配置修改、以优化集群安全性和性能。

例如，假设您为群集配置的网络时间协议 (NTP) 服务器数量少于建议数量。为了帮助您防止不准确的群集时间可能导致的问题，Insights 会通知您配置的 NTP 服务器太少，并提供了了解详细信息、解决问题或将其忽略的选项。

image:insights.png["System Manager洞察页面的屏幕截图"]

.步骤
. 在System Manager中、选择*洞察力*。
. 审查建议。


.下一步行动
执行任何必要的操作以实施最佳实践并优化集群安全性和性能。
