= 使用 ASA r2 system Insights 优化集群安全性和性能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
查看ONTAP系统管理器中的_洞察力_、确定可在ASA R2系统上实施的最佳实践和配置修改、以优化集群安全性和性能。

例如，假设您的集群配置了网络时间协议 (NTP) 服务器。但是，您并不知道您拥有的 NTP 服务器数量低于最佳集群时间管理所需的建议数量。为了帮助您防止集群时间不准确时可能发生的问题，Insights 会通知您配置的 NTP 服务器太少，并提供了解该问题的更多信息、修复问题或将其关闭的选项。

image:insights.png["System Manager洞察页面的屏幕截图"]

.步骤
. 在System Manager中、选择*洞察力*。
. 审查建议。


.下一步行动
执行任何必要的操作以实施最佳实践并优化集群安全性和性能。
