= 了解适用于 ASA r2 存储系统的 SnapLock 数据保护
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP SnapLock 是一种高性能合规性解决方案，适用于使用 WORM 存储以未修改形式保留文件以满足监管和治理目的的组织。您可以在 Compliance 或 Enterprise 模式下运行 SnapLock，这两种模式提供不同级别的 WORM 数据保护。SAN 环境中的主集群不支持 SnapLock Compliance 和 Enterprise 模式，但您可以在二级系统上为 SnapVault 启用 SnapLock，以防止二级快照被意外或恶意删除。

必须初始化 SnapLock Compliance Clock，才能使用 SnapLock for SnapVault 保护辅助系统上的快照。

.相关信息
* 详细了解link:https://docs.netapp.com/us-en/ontap/san-admin/configure-backup-vaults-san-environment-concept.html["SnapLock for SnapVault 在 SAN 环境中的使用"^]。
* 详细了解link:https://docs.netapp.com/us-en/ontap/snaplock/index.html["ONTAP SnapLock"^]。




[[initialize-the-snaplock-compliance-clock]]
== 初始化 SnapLock 合规时钟

如果要使用 SnapLock for SnapVault 保护辅助系统上的目标快照，必须首先在本地和目标集群上初始化 SnapLock Compliance Clock。

.步骤
. 选择 * 集群 > 概述 * 。
. 在*N节点*部分中，选择*初 始化SnapLock Compliance Clock*。
. 选择*初始化*。
. 确认合规时钟已初始化。
+
.. 选择 * 集群 > 概述 * 。
.. 在*节点*部分中，选择image:icon_show_hide.png["白色背景上的三个蓝色列"]；然后选择* SnapLock Compliance Clock*。




.下一步是什么？
在本地和目标集群上初始化 SnapLock 合规时钟后，您就可以 link:../data-protection/snapshot-replication.html["创建与 SnapLock for SnapVault 的复制关系"]。
