= 提交并查看ASA R2存储系统的支持案例
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您遇到需要帮助的问题，请使用 ONTAP System Manager 向技术支持提交案例，或查看已关闭或正在处理的案例。

您必须link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["已向Active IQ注册"^]才能查看 ASA r2 系统的支持案例。

.步骤
. 要提交支持案例，请在 System Manager 中选择 *Cluster > Support*，然后选择 *Go to NetApp Support*。
. 要查看以前提交的案例，请在 System Manager 中选择 *集群 > 支持*，然后选择 *查看我的案例*。
