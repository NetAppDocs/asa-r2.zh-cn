= 在ASA r2 系统上创建主机组
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 ASA r2 系统上，_主机组_是用于授予主机对存储单元的访问权限的机制。主机组是指 SCSI 主机的 igroup 或 NVMe 主机的 NVMe 子系统。主机只能看到映射到其所属主机组的存储单元。当主机组映射到存储单元时，属于该组的主机就可以挂载（在存储单元上创建目录和文件结构）该存储单元。

创建存储单元时，系统会自动或手动创建主机组。您可以选择使用以下步骤在创建存储单元之前或之后创建主机组。

.步骤
. 在System Manager中，选择*Host*。
. 选择要添加到主机组的主机。
+
选择第一个主机后、用于添加到主机组的选项将显示在主机列表上方。

. 选择*添加到主机组*。
. 搜索并选择要添加主机的主机组。


.下一步是什么？
您已创建主机组，现在可以link:provision-san-storage.html#map-the-storage-unit-to-a-host["将其映射到存储单元"] 。
